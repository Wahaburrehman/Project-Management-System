# Grove — Project Management System

A modern, responsive project management dashboard built with React and Tailwind CSS. Grove helps users organise tasks, monitor project progress, and manage their workspace through a clean interface inspired by ivory, forest, charcoal, and sage colours.

## Features

- Dashboard with project and task statistics
- Project cards with progress bars and deadlines
- Create tasks with form validation
- Update task statuses and delete tasks
- Search tasks by title, project, or status
- Filter tasks by status
- Team members overview
- Monthly calendar interface
- Workspace settings page
- Responsive sidebar and mobile navigation
- Toast notifications and interactive UI elements

## Tech Stack

- React
- Tailwind CSS
- JavaScript (ES6+)

- Lucide React
- HTML5 and CSS3

## Usage

- Navigate between dashboard sections using the sidebar.
- Create tasks using the New Task button.
- Update task statuses using the status control.
- Search and filter tasks to find specific work.
- Review project progress and team information.

## Design Approach

The interface uses an ivory background, forest-green accents, charcoal text, and sage highlights. Responsive layouts, reusable components, subtle transitions, and consistent spacing help keep the dashboard easy to navigate.
